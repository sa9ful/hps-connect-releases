হেরিটেজ পাবলিক স্কুল, ফরিদপুর-এর শিক্ষক ও স্টাফদের যোগাযোগ অ্যাপ।

এরপর থেকে অ্যাপের মেনুর "অ্যাপ আপডেট" থেকেই নতুন ভার্সন বসানো যাবে।

## উইন্ডোজ কম্পিউটার/ল্যাপটপ (৬৪-বিট)

[HPS-Connect-Setup-latest.exe](https://github.com/sa9ful/hps-connect-releases/raw/main/HPS-Connect-Setup-latest.exe) (v1.16.5, ২৬ MB, অ্যাপের মতো নীল রঙ)

ফোনের মতো একই আইডি/পাসওয়ার্ডে লগইন, একই ডেটা। পুশ নোটিফিকেশন ও কল শুধু ফোনে; কম্পিউটারে অ্যাপ খোলা থাকলে নোটিশের নোটিফিকেশন আসে।
